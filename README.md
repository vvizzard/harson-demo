# HARSON Group — demonstration du nouveau site

Ce depot ne contient **que la demonstration statique construite**, destinee a etre consultee par HARSON Group. Il ne contient ni le code source du site, ni l'API, ni l'espace d'administration.

## Limites de cette demonstration

- Contenus partiels : 9 realisations sur 30.
- Formulaire de contact sans envoi reel.
- Espace d'administration non inclus.
- Connexion Internet necessaire pour les polices et la carte.

Les pages portent une balise `noindex` et `robots.txt` interdit l'indexation : cette demonstration n'a pas vocation a apparaitre dans les moteurs de recherche.
